HTML

A standard markup language used to create and structure web pages. It organizes content such as text, images, links, and other elements that appear on a website.

Recommended Resources

1. Scrimba

If you're interested in diving into HTML, We recommend checking out Scrimba. They offer video lessons where they'll take you through different HTML concepts while allowing you to interactively work with the code. You'll have the opportunity to pause their lesson, mess around with the code yourself, and immediately see how those edits impact things.

Start Learning

2. W3Schools

Need somewhere to revisit your HTML topics when you need them? Head over to W3Schools' collection of written lessons on a range of different HTML topics. W3Schools' website gets a little more exciting with their adventure mode, where you can take breaks between studying and test out some fun (and educational) coding puzzles instead.

Start Learning

3. Codedex

Learning HTML can be more enjoyable when there's a little fun involved! Codedex turns the learning process into a coding adventure rather than a typical set of lessons. It also lets you explore HTML concepts through interactive activities while taking your time with each lesson.

4. Coddy Tech

With Coddy Tech's interactive classes, you'll be able to learn exactly how HTML works by exploring HTML via their site. Each lesson will provide both explanations of topics and opportunities for writing code and experimenting with different HTML elements to produce an actual webpage.

5. Sololearn

SoloLearn allows you to dive straight into the world of HTML with easy lessons covering various concepts. The website has tons of quizzes and coding challenges which allow you to sharpen your understanding as well. Sololearn makes learning HTML easy!

6. The Odin Project

The Odin Project provides a completely free curriculum designed for beginners. You'll learn the fundamentals behind how HTML works by working with elements, tags, and finally writing and structuring your own webpages. Through hands-on projects, you'll be able to apply your learning.

7. MDN Web Docs

MDN Web Docs has all the information you might be looking for. With beginner-friendly HTML lessons with examples covering basic structure and elements as well as more advanced stuff like links, images, lists and forms.
