CSS

A styling language used to make web pages look better. It controls colors, fonts, spacing, and layouts, helping turn simple HTML pages into attractive and well-designed websites.

Recommended Tutorials

1. Bro Code

Bro Code has a great tutorial on his YouTube channel. The tutorial playlist has 13 videos covering all the basics of CSS and showing you how to style your web pages using various properties like colors, fonts, layouts, etc. You can follow along with these amazing lessons and give your web pages some awesome touches of your creativity.

Start Learning

2. Kevin Powell

We recommend watching Kevin Powell's playlist on this topic. In his playlist of 35 videos, he teaches how to style and design beautiful web pages using some key concepts like selectors, colors, typography, layouts, flexbox, responsive design, and more. He breaks down all these complex ideas into easy lessons that make learning this language easier.

Start Learning

3. Dave Gray

Dave Gray's tutorial playlist contains 28 videos that will help you learn all of the essentials needed for working with selectors, colors, typography, the box model, positioning, flexbox, grid, animations and responsive design. It even has mini projects as well as an end website project where you can practice applying everything you have learned together!

Start Learning

Recommended Resources

1. Scrimba

You've heard about coding bootcamps before, but what if we told you there was another way? If you learn best by doing, you might find this website called Scrimba useful. Instead of just sitting around watching an instructor code, you'll be able to pause the lesson and experiment for yourself.

Start Learning

2. W3Schools

We really recommend trying W3Schools to get comfortable with different areas of CSS. Its adventure mode lets you discover different parts of CSS in a fun environment through short coding challenges and puzzles. W3Schools provides resources covering all the important topics related to CSS for beginners as well as advanced learners.

Start Learning

3. Codedex

Codedex gives beginner-friendly lessons on styling webpages with CSS. But instead of being boring, you'll feel like you're on a fun adventure thanks to the website's game-inspired design that includes things like pixel art visuals, and badges. You'll be able to go through all these lessons at your own pace.

Start Learning

4. Coddy Tech

Coddy Tech has interactive lessons with simple explanations, as well as code writing challenges to allow practicing what you've learned on the fly! You'll be able to try different color combinations, font sizes, layout arrangements, spacing options, and more CSS properties! This helps beginners grasp fundamental concepts in CSS and hone their style writing skills one lesson at a time!

Start Learning

5. Sololearn

Learning CSS shouldn't be hard. With these awesome courses from Sololearn you will start exploring different topics of website styling. Additionally, you get a chance to test your knowledge on various quizzes and even code challenges. So whether you want to know about colors or create cool layout styles there is a lot for you to discover in this website.

Start Learning

6. Flexbox Froggy

Try out this fun little puzzle game called Flexbox Froggy that will teach you more about using flexbox layout. Your mission is to help froggy and his friends reach their matching lily pads by writing some CSS code. There are 24 levels, each teaching different properties such as justify-content, align-items, and flex-direction!

Start Learning

7. Grid Garden

Grid Garden turns CSS Grid into a series of fun puzzles where you use code to guide water toward growing carrots while avoiding the weeds. Moreover, as you progress through its 28 levels, you'll get to experiment with properties like grid-column, and grid-row to control how elements are arranged.

Start Learning

8. SmolCSS

If you're looking for inspiration on which CSS project to take on next, head over to SmolCSS. This website contains tons of little code snippets that help you achieve everything from creating different layouts to building components. You'll find examples ranging from making a responsive grid all the way to basic stuff like centering elements.

Start Learning

9. QuickRef

We've got you covered with this handy CSS cheatsheet from QuickRef. This great resource pulls together a ton of helpful references. You'll find things like selectors, colors, fonts, spacing, positioning (including flexbox and grid), and more, all along with code examples showing you how they work.

Start Learning

10. OverAPI

Do you remember which CSS property you used for this and what is its usage? Or maybe you want a quick reminder on using some specific properties. Then you should definitely check out these CSS cheatsheets from OverAPI right away. They have various properties listed with their syntax and examples.
